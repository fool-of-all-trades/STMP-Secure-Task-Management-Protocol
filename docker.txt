# Uruchomienie kontenera tylko z bazą (bez Dockerfile i bez plików Dockera w projekcie)

1. Uruchomienie w Dockera:
docker run --name stmp_postgres -e POSTGRES_USER=stmp_user -e POSTGRES_PASSWORD=stmp_pass -e POSTGRES_DB=stmp_db -p 5432:5432 -d postgres:15


2. Dodanie do bazy tabel:
cat schema.sql | docker exec -i stmp_postgres psql -U stmp_user -d stmp_db


3. Testowanie bazy:
1. docker exec -it stmp_postgres psql -U stmp_user -d stmp_db
2. SELECT id, username, password_hash, failed_login_count, locked_until FROM users;
